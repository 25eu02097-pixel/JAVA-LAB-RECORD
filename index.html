Lab Weeks

Week 1

Aim

To compare Java with other popular languages and to install the JDK, configure it and run a first program on Windows.

Tasks Performed

  • Compared Java, C, C++, Python and JavaScript on features such as memory management, security and performance.
  • Matched languages to needs like system programming, enterprise apps, web, AI and mobile.
  • Installed Oracle JDK and OpenJDK, and checked them with java --version and javac --version.
  • Set JAVA_HOME and added %JAVA_HOME%\bin to PATH.
  • Wrote, compiled and ran the Hello World program.
